## Project Description
The Technology and Device Management System is a menu-driven C++ program for managing electronic device records. It stores device names, categories, quantities, prices, conditions, and monthly usage hours.

## Program Features
1. Add a device and automatically assign a device ID.
2. View all saved device records.
3. Search for a device using its ID.
4. Update an existing device record.
5. Delete a device record.
6. Display an inventory summary.
7. Exit the program.

## C++ Concepts Used
- One-dimensional arrays for device information
- Two-dimensional arrays for monthly usage
- Functions
- `for` loops and a `do-while` loop
- `if` / `else` conditions
- Input and output using `cin`, `cout`, and `getline`
- Basic arithmetic operations

## Files in This Repository
- `Technology_Device_Management.cpp` — final C++ source code

## How to Run
1. Open the `.cpp` file in Code::Blocks or another C++ IDE.
2. Build and run the program.
3. Choose an option from the menu and follow the prompts.

## Notes
The program stores records in arrays while it is running. Records are not saved permanently after the program is closed. The project documentation PDF is included in the separate GitHub-ready ZIP prepared for submission.
